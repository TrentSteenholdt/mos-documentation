    Admin: User Management

    Access Level

    Owner access required

    Overview

    Manage all users in your organisation through the User Management page. View user lists, search for members, edit user details, create new accounts, change user names, reset passwords, manage group membership, upload profile pictures, and export user data.

    How to Access

    Click Admin then User Management

    Page Layout

    When you open the page you see:

    Search and Filter Section

    • Search box to find users by name or username
    • Group filter dropdown if you manage multiple groups
    • Search and All Users buttons

    Export Section

    • Export button to download user list as CSV

    User List Table

    • User profile pictures
    • Full names
    • Email addresses and phone numbers
    • Group memberships
    • Edit and action buttons

    Searching for Users

    Captured 25 October 2026. The member information shown is fictional.

    Search from the page header

    Use the Search users... box at the top of a page to find a member without first opening User Management. Enter their name to show a result card. Select View Profile to view the member's profile, or Edit User in the administration row to open their record. Assessment buttons appear together on the Assessments row.

    Captured 25 October 2026.

    Search by Name or Username

    To find specific users:

    1. Enter a name or username in the Search User box
    2. Click Search
    3. Result: Only matching users appear in the table

    Filter by Group

    If you manage multiple groups:

    1. Click the Filter by Group dropdown
    2. Select a group
    3. Result: Only users from the selected group appear

    View All Users

    To return to the full list:

    1. Click All Users
    2. Result: The complete user list displays

    Editing User Details

    To update a user's information:

    1. Click Edit next to the user's name in the list
    2. The page switches to edit view showing the user's current information

    You can update these sections:

    Address Section

    Captured 25 October 2026.

    Search Address

    • Type an address in the search box
    • Select from the dropdown suggestions
    • Click Save Changes to apply the selected address

    Current Address

    • Shows the currently saved address
    • Read only display

    Phone Numbers

    • Phone Number - Primary contact number
    • Work Number - Work contact number
    • Secondary Number - Additional contact number

    Personal Details Section

    Captured 25 October 2026.

    Secondary Email Address

    • An additional email address saved on the member's profile.

    Shirt Size

    • Optional profile detail. Enter the member's shirt size if it is useful to your organisation.

    Pants Size

    • Optional profile detail. Enter the member's pants size if it is useful to your organisation.

    Joined Your Group

    • The year the member joined your group.

    About Me Section

    Rich text editor for user biography:

    • Use formatting toolbar for bold, italic and lists
    • Add links and formatted text
    • Displays on user profile page

    When the AI features add-on is active and your role has AI Rewrite access, the editor shows a purple AI Rewrite button. Write a draft first, then select a passage to rewrite only that passage or leave it unselected to rewrite the whole biography. Review the result before saving the user's profile. See AI Features for access settings and troubleshooting.

    Profile Picture Section

    Captured 25 October 2026.

    Only appears if the user belongs to groups where you have administrator access:

    Upload Picture

    1. Click Upload Picture

    2. In the Upload Profile Picture dialog, use Choose File or click Select Picture to open the file picker.

      Captured 25 October 2026.

    3. Select a JPG, PNG or GIF image that is no larger than 2 MB

    4. Adjust the square crop, then click Crop & Upload
    5. Result: The profile picture updates

    Image Requirements

    • Formats: JPG, PNG, GIF
    • Maximum size: 2 MB
    • Automatically cropped to square

    Remove Picture

    1. Click Remove Picture
    2. Confirm the deletion
    3. Result: Picture is deleted and replaced with default avatar

    Alternative Method

    You can also delete profile pictures from the Media page, which allows you to manage multiple profile images at once or delete orphaned profile pictures.

    Multiple Groups

    If the user belongs to multiple groups:

    • Select which group to upload the picture for using the dropdown
    • Pictures are stored separately for each group

    Saving Changes

    After making updates:

    1. Click Save Changes at the top or bottom of the page
    2. Result: Confirmation message appears and changes are saved
    3. Click Back to return to the user list

    Changing a User's Name

    The Change Name action appears in the member's header card when the account supports administrator name changes. It is not shown for every account.

    To change a user's first name or surname:

    1. Click Edit user next to the person's name
    2. In the member header card at the top of the edit page, click Change Name
    3. Enter the required First Name and Last Name
    4. Click Update Name
    5. Result: MOS confirms the change and refreshes the member details

    Name Validation

    • Names must contain only letters, spaces, hyphens and apostrophes
    • Both name fields are required

    Username Changes

    When you change a user's name, MOS updates their username using the new name. If that username is already in use, MOS adds a number to make it unique.

    The user receives a confirmation email about the name change.

    Group Membership

    To view and manage which groups a user belongs to:

    1. Click Edit user next to the user's name
    2. Scroll to the Group Membership section
    3. Review the groups, the licences remaining in each group, and the Member switch.

    Captured 25 October 2026.

    To add or remove the user from a group, turn its Member switch on or off. The change is saved immediately.

    Tip

    To change access levels or assign roles such as Viewer, Reviewer, Trainer, Communications, or Files Manager, use Membership and Roles.

    Creating New Users

    Add Single User

    To create one new user:

    1. From Admin, select New user
    2. The Create a new user form appears
    3. Enter:
      • First Name (required)
      • Surname (required)
      • Email Address (required) - Valid email format
    4. Click Create User

    What Happens Next

    Result: MOS confirms the account details and opens the new member's record, where you can review group membership and add profile details. MOS sends a welcome email with sign-in details.

    Bulk Import Users

    To add multiple users from a CSV file:

    1. From Admin, select Bulk import
    2. Click Download Example CSV to get the template
    3. Fill in the template with these columns:
      • FirstName
      • Surname
      • Email
    4. Select your completed file
    5. Click Upload & Preview
    6. Review each row and its status
    7. Fix any rows with errors and upload the corrected file again if needed
    8. Click Process [number] User(s) to continue with the valid rows
    9. Result: MOS shows the outcome for each row

    Validation

    Rows are checked for:

    • Required first name, surname and email address
    • Valid email format
    • Duplicate email addresses within the file

    If an email address already belongs to an account, the preview marks the row as a warning and explains whether that account will be added to your group or restored.

    Preview Table

    The preview shows a table with these columns:

    • #: Row number from the CSV
    • First Name: User's first name
    • Surname: User's surname
    • Email: User's email address
    • Status: Badge showing Valid, Warning, or Error
    • Detail: Explanation of any issue found

    Results

    After processing, MOS shows the result for each row.

    Warning

    Check that you have enough available licences before importing.

    Resetting User Passwords

    You can reset a user's password when they forget it or need a temporary password.

    Availability: This action only appears for accounts that support password reset.

    To reset a user's password:

    1. Find the member in the user list and click Reset password.
    2. Review the Confirm Password Reset message
    3. Click Reset Password to confirm
    4. Result: MOS confirms the reset and sends the user an email with temporary sign-in details

    Deleting Users

    To remove a user from the system:

    1. Find the member in the user list and click Delete user
    2. Review the confirmation message
    3. Click Delete User to confirm
    4. Result: MOS removes the user and refreshes the list

    Captured 25 October 2026.

    Warning

    If the person belongs to multiple groups, deleting them removes them from all groups. To remove them from only one group, use the Member switch in Group Membership.

    Before Deleting

    Consider if you should:

    • Remove them from specific groups instead of deleting entirely
    • Lower their access level instead
    • Keep the account but inform the user they no longer have access

    Exporting Users

    Captured 25 October 2026.

    To download your complete user list:

    1. Click Export in the Export Users section
    2. Result: CSV file downloads to your computer

    CSV Contents

    The export includes:

    • Username and name
    • Email and secondary email address
    • Last login date
    • Address and contact numbers
    • Groups the user belongs to

    Uses

    • Audit records and compliance reporting
    • Import into other systems
    • Analysis and planning
    • Backup documentation
    • Licence verification

    Pagination

    If you have many users:

    • 10 users display per page
    • Pagination controls appear at the bottom
    • Click page numbers to navigate
    • First, previous, next and last buttons available

    Multiple Group Management

    If you administer multiple groups:

    Group Filter

    • Filter dropdown appears in the search section
    • Select a group to view only its members
    • Select All Groups to view everyone

    Multiple Groups Alert

    If you belong to multiple groups with administrator access:

    • Alert banner appears at the top
    • Shows which groups you can manage
    • Helps you understand which users you can edit

    Validation Rules

    First Name and Surname

    • Both fields are required when creating a user or changing a name
    • The Change Name form allows letters, spaces, hyphens and apostrophes

    Email Address

    • Must be valid email format
    • Must contain @ symbol
    • Must have domain extension
    • Examples: user@example.com, name.surname@domain.co.au

    Address

    • Search for a new address and choose a suggestion
    • The current address is read-only; save the form to apply the selected address

    Tips

    Best Practices

    • Update user details when their contact information changes
    • Export your user list when you need a current copy
    • Use bulk import for adding multiple users at once
    • Check licence availability before adding users
    • Use search to find users quickly in large lists
    • Remove users from groups they no longer need access to instead of deleting

    When Changing Names

    • Inform the user before changing their name
    • Confirm spelling with the user
    • Tell them their username will change

    Profile Pictures

    • Upload clear professional photos
    • Use consistent image quality across your organisation
    • Images are cropped to squares automatically
    • File size affects page load speed

    Troubleshooting

    Cannot Edit User

    Symptoms

    • Edit button is greyed out or missing
    • Error when clicking Edit

    How to Fix

    1. Verify you have Owner access
    2. Check the user belongs to a group you administer
    3. Refresh the page
    4. Log out and log back in

    Common Causes

    • Insufficient permissions
    • User belongs to a different group
    • Session expired

    Add an existing MOS user to your group

    Use the Member switch in the user's Group Membership section. See Group Membership.

    Bulk Import Errors

    Symptoms

    • Some rows fail to import
    • Error messages appear in results

    How to Fix

    1. Check CSV format matches the template exactly
    2. Verify all email addresses are valid
    3. Remove any duplicate emails
    4. Check that each row has a first name, surname and email address
    5. Save the file in CSV format
    6. Try uploading a smaller batch

    Common Causes

    • Invalid email format
    • Duplicate emails
    • Wrong file format
    • Special characters in names
    • Missing required columns

    Profile Picture Not Uploading

    Symptoms

    • Upload button does not work
    • Error message when uploading
    • Picture does not appear

    How to Fix

    1. Check file size is under 2 MB
    2. Verify file format is JPG, PNG or GIF
    3. Try a different image file
    4. Check your internet connection
    5. Refresh the page and try again

    Common Causes

    • File too large
    • Unsupported file format
    • Network connection issues
    • Browser cache problems
