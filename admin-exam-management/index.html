    Exam Management: Create and Manage Exams

    Access Level

    Trainer or Owner access is required.

    Overview

    Exam Management lets you create exams, configure availability and scoring, add questions, and review completed attempts. You can write questions yourself or, when enabled for your group, generate private AI-assisted drafts from source material.

    How to access

    Click Learning Management then Exams.

    Exam List

    The exam list shows each exam's name, availability status, pass mark, number of questions presented, time limit, and start and end dates.

    Available actions include:

    • Results, shown after users have completed the exam
    • Questions or Add questions
    • Edit
    • Delete
    • Clone, shown after questions have been added

    Create an Exam

    1. Click New exam.
    2. Complete the exam details and settings.
    3. Click Save.
    4. Result: The exam appears in the exam list.

    Exam Fields

    Name, required

    • Enter a short name for the exam.
    • Use letters, numbers, spaces, underscores, full stops, or hyphens.

    Questions, required

    • Enter how many questions should be randomly presented from the question pool.
    • Enter 0 to present every question.

    Time limit, required

    • Enter the number of minutes allowed.
    • Enter 0 for no time limit.

    Pass mark %, required

    • Enter a value from 1 to 100.

    Completion required, optional

    • Select this when users must sit the exam before its end date.

    Allow resits, optional

    • Select this to let users attempt the exam again after failing.

    Notify on completion, optional

    • Select this to email group administrators when a user completes the exam.

    Start date, required

    • Sets the first day the exam is available.

    End date, required

    • Sets the last day the exam is available.

    Exam Description, optional

    • Add instructions or information shown before a user starts the exam.

    Exam End Description, optional

    • Add information shown after a user submits the exam.

    Add a Question Manually

    1. Find the exam and click Questions or Add questions.
    2. Click New question.
    3. Enter the question text.
    4. Optionally click Insert image and select an image.
    5. Select Single, Multiple, or True/False.
    6. For Single or Multiple, select the number of answers and enter every answer.
    7. Mark the correct answer or answers.
    8. Click Save.
    9. Result: The question is added to the exam's question pool.

    Question Rules

    • Question text is required.
    • Every displayed answer field must be completed.
    • A Single question requires one correct answer.
    • A Multiple question requires at least two correct answers.
    • A True/False question requires you to select either True or False as the correct answer.
    • A question with no defined answer displays No answer defined and does not appear in the exam.

    Generate Private Question Drafts with AI

    This feature appears only when AI features and AI exam question drafting are enabled for your group and role.

    Before You Start

    • Prepare the relevant laws, playing conditions, or other authoritative material.
    • You can paste source text, upload PDF, Word, or plain-text documents, or use both.
    • You can upload up to five documents. Each document must be no larger than 10 MB.
    • Keep the page open while the source is read and drafts are generated.
    • AI-generated content may be wrong. A person must verify every question and answer against the source before publication.

    Generate a Draft Batch

    1. Find the exam and click Questions.
    2. Click Generate with AI.
    3. Paste source material into Paste playing conditions or laws, upload documents under Source files, or do both.
    4. In Questions, enter a number from 1 to 20.
    5. Select Mixed, Easy, Medium, or Hard under Difficulty.
    6. Optionally enter a topic in Optional topic or focus.
    7. Select at least one question type: Single answer, Multiple answer, or True/False.
    8. Click Generate private drafts.
    9. Wait for the progress window to close. The review workspace opens when processing finishes.

    The system may create fewer questions than requested when the supplied material does not support enough clear, distinct questions.

    Review an AI Draft

    Each draft shows:

    • The question and question type
    • The source used
    • Every answer marked Correct or Incorrect
    • Reviewer reasoning for every answer
    • A source locator and exact supporting excerpt

    Reasoning and source evidence are displayed as readable review content. They only become text boxes after you click Edit draft.

    Verify and Add a Draft to the Exam

    1. In Retained sources, expand the source and click open original when available.
    2. Read the cited source at the displayed locator.
    3. Check the question wording.
    4. Check every answer, its Correct or Incorrect marking, and its reasoning.
    5. Check that the exact supporting excerpt supports the entire question.
    6. If everything is accurate, select I checked this question, every option, and the marked answers against the retained source.
    7. Click Verify and add to exam.
    8. Confirm publication.
    9. Result: The draft is added to the exam question pool and marked as published.

    Human Verification Is Mandatory

    Do not publish from AI output alone. The recorded human check is the final authority for the question and its answers.

    Edit a Draft

    1. Click Edit draft.
    2. Update the question, type, source, answer text, correct-answer markings, reasoning, locator, or supporting excerpt.
    3. Click Save changes.
    4. Review the saved draft again against the retained source.
    5. Complete the verification steps before publishing.

    Any edit clears the previous verification. Click Cancel to discard unsaved edits.

    Regenerate or Reject a Draft

    • Click Regenerate and confirm to replace the draft with a new source-grounded suggestion. The replacement must be verified again.
    • Click Reject and confirm when a draft should not be added to the exam.

    Resume or Delete Drafts

    1. Open the exam's question list.
    2. Click Resume AI drafts.
    3. Click Review beside a batch to continue checking it.
    4. Click Delete to remove a batch and its retained private sources.

    Deleting a draft batch does not remove questions that were already published to the exam.

    Edit or Delete an Existing Question

    • Click Edit beside a question to change it.
    • Once a user has answered a question, editing is disabled to protect completed attempt records.
    • Click the delete button and confirm to remove a question.

    Clone an Exam

    1. Find an exam that contains questions.
    2. Click the Clone button.
    3. Confirm the action.
    4. Result: A copy of the exam is added to the exam list.

    Review and Export Results

    1. Click Results beside an exam.
    2. Review each user's pass or fail result, mark, correct and incorrect totals, completion time, and attempt count when resits are enabled.
    3. Click View to open an individual attempt.
    4. Click Export Results to download the results for your records.

    Troubleshooting

    Generate with AI is not visible

    The group's AI master setting or exam-question drafting setting may be disabled, or the feature may not be available to your role. Ask a group owner to check Admin, Group Settings, Features, then AI features.

    No drafts were generated

    You may see: The supplied material did not support any valid questions. Narrow the source or focus and try another batch.

    Try a more specific section of the source, enter a narrower focus, or select question types that suit the material.

    A source document cannot be processed

    Check that it is a supported PDF, Word, or plain-text document, is no larger than 10 MB, and contains selectable text. Scanned images without readable text may not produce questions.

    A draft cannot be published

    Confirm that you selected the verification statement. If the draft was edited or regenerated, review it again before publishing.

    An existing question cannot be edited

    Someone has already answered that question. Create a replacement question instead.
