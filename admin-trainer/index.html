    Trainer Management: Create Training Packs and Review Sessions

    Access Level

    Trainer or Owner access is required. Trainer must also be enabled for the group.

    Overview

    Trainer Management lets you create reusable scenario packs, choose who can access them, and review user sessions. You can write packs yourself or ask AI to suggest drafts from recent development evidence.

    How to access

    Click Learning Management then Trainer.

    The page contains two sections:

    • Training Packs for creating and maintaining packs
    • User Sessions for reviewing users' progress, answers, scores, and feedback

    Create a Training Pack Manually

    1. Open Training Packs.
    2. Click New Pack.
    3. Enter a Pack name.
    4. Optionally enter a Description.
    5. Choose the evidence and audience settings.
    6. Click Add Scenario.
    7. Complete the scenario fields.
    8. Add further scenarios when required.
    9. Turn on Active when the pack is ready for users.
    10. Click Save and Close or Save and Continue Editing.
    11. Result: The pack is saved. Active packs are available to the selected audience.

    Pack Fields

    Pack name, required

    • Use a clear name that users and trainers will recognise.

    Active, optional

    • Only active packs can be started by users.
    • Leave this off while reviewing a new or AI-suggested pack.

    Manual review, optional

    • Turn this on when a trainer must check and release coaching feedback before the user can see it.
    • The user is emailed when feedback is released.

    Description, optional

    • Explain what the pack develops and when users should complete it.

    Evidence scope, required

    • Select Whole group evidence to use relevant records from across the group when requesting AI suggestions.
    • Select Selected subgroup evidence to restrict suggestions to selected subgroups.

    Target subgroups, optional

    • Leave this blank to make an active pack available across the group.
    • Select one or more subgroups to restrict who can see and start the pack.

    Scenario Fields

    Title, required

    • Enter a short name for the scenario.

    Internal scoring benchmark, required

    • Enter a value from 1 to 100.

    Prompt, required

    • Describe the situation and what the user must respond to.

    Rubric, required

    • Describe what a strong answer should demonstrate.

    A pack must contain at least one complete scenario before it can be saved.

    Ask AI to Suggest a Pack

    AI suggestions are drafts. Review every scenario, rubric, and scoring benchmark before activating the pack.

    1. In Training Packs, click Suggest a Pack.
    2. Optionally enter Focus areas.
    3. Select an Evidence period.
    4. Select at least one evidence source: Diaries, Assessments, or Development plans.
    5. Click Continue.
    6. Review the suggested pack in the Pack Editor.
    7. Edit the name, description, audience, scenarios, rubrics, and scoring benchmarks as needed.
    8. Turn on Active only when the pack is ready.
    9. Save the pack.

    If you select Selected subgroup evidence, you must select at least one subgroup.

    Ask AI to Suggest a Scenario

    1. Create or open a pack.
    2. Make sure the pack has a name, description, or other clear direction.
    3. Click Suggest a Scenario.
    4. Optionally enter Focus areas.
    5. Select the evidence period and at least one evidence source.
    6. Click Continue.
    7. Review and edit the suggested title, prompt, rubric, and scoring benchmark.
    8. Save the pack.

    AI uses the selected development evidence only when a trainer requests a suggestion. It does not generate new scenarios when a user starts a session.

    Edit or Delete a Pack

    • Select a pack to open it in the Pack Editor, make changes, then click Save and Close or Save and Continue Editing.
    • Turn off Active to stop new users from starting the pack.
    • Click the pack's delete action, then click Delete Pack to confirm permanent removal.

    Review User Sessions

    1. Open the User Sessions tab.
    2. Find the session by user, pack, date, status, or summary.
    3. Open the session.
    4. Review each scenario's Prompt, Response, score, and Coaching Feedback.
    5. Click Print when you need a printable session record.
    6. Click Close to return to the session list.

    Session statuses include In progress, Awaiting review, and Completed.

    Release Manually Reviewed Feedback

    When Manual review is enabled for a pack:

    1. Open User Sessions and select a session marked Awaiting review.
    2. Open the scenario's Coaching Feedback tab.
    3. Review and, if required, edit Coaching feedback shown to the user.
    4. Optionally enter Internal review notes for trainers.
    5. Click Release feedback and notify user.
    6. Result: The feedback becomes visible to the user and the user is emailed.

    Delete a User Session

    1. In User Sessions, click the session's delete action.
    2. Confirm the warning.
    3. Result: The session is permanently removed.

    Troubleshooting

    Trainer is not enabled

    If the page shows Trainer is not enabled, the feature is not available for the group. A group owner can review the group's billing and AI feature settings.

    No evidence matched the selected controls

    Widen the evidence period, select another evidence source, choose a different subgroup, or add a scenario manually.

    AI is temporarily unavailable

    Keep your existing pack content and try the suggestion again later. You can always add a pack or scenario manually.

    The pack will not save

    Check that the pack has a name and at least one scenario. Every scenario requires a title, prompt, rubric, and scoring benchmark from 1 to 100.

    Printing does not open

    Allow pop-ups for MOS, reopen the session, and click Print again.
